# Third-party components and licences

Calm Garden itself is MIT-licensed (see `LICENSE`). It uses or ships:

| Component | Used for | Licence | Shipped? |
|---|---|---|---|
| SDL2 2.x | window, input, timing, rendering of the canvas | zlib (`docs/licenses/SDL2-zlib.txt`) | Windows: `SDL2.dll`; Linux: system package |
| SDL2_ttf 2.22 / 2.24 | font rasterising and text shaping | zlib | Windows: `SDL2_ttf.dll`; Linux: system package |
| HarfBuzz | text shaping inside SDL2_ttf | MIT ("Old MIT") | inside `SDL2_ttf.dll` / system package |
| FreeType | glyph rasterising inside SDL2_ttf | FreeType Licence (BSD-style) | inside `SDL2_ttf.dll` / system package |
| BASS 2.4 (Un4seen Developments) | sound output (optional) | proprietary; free for non-commercial use, commercial licences available (`docs/licenses/BASS-licence-excerpt.txt`) | `bass.dll`, `lib/linux64/libbass.so` |
| Noto Sans, Noto Sans Hebrew (Regular, Bold) | interface fonts | SIL Open Font Licence 1.1 (`docs/licenses/OFL-1.1.txt`) | `assets/fonts/` |
| DejaVu Sans | fallback glyphs | Bitstream Vera / DejaVu licence (`docs/licenses/DejaVu-copyright.txt`) | `assets/fonts/` |
| GNU FriBidi | only in `tests/test_fribidi.bas` (comparison) | LGPL 2.1+ | not shipped |
| Unicode data files | `tests/data/` (conformance test) | Unicode Licence v3 | test data only |

**BASS note.** BASS is not open-source software. Calm Garden loads it at run time
only if it is present, and works fully (silently) without it. If you distribute
Calm Garden commercially, either obtain a BASS licence or remove `bass.dll` /
`libbass.so` from your package.

**Pictures and sounds.** All artwork (flowers, scenes, icons) and all sounds
(ambient loops, chimes, effects) are generated by Calm Garden's own code and are
covered by the MIT licence. No external images or recordings are included.
